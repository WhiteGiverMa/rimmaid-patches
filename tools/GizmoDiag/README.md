# Gizmo Diagnostic

[中文说明](README.zh-CN.md)

Inactive diagnostic mod used to sample gizmo and selection-overlay draw time. It is kept under `tools/` because it produces periodic log output and is not a gameplay patch.

`Source/GizmoDiag.decompiled.cs` was recovered from the retained DLL with ILSpy 11.0.0 on 2026-09-15. The original source file was no longer available.
